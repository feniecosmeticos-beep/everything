# Logos das marcas no catálogo

Incluídos em 14/10/2026 nos cartões de marcas do início e da página Marcas. Os nomes e a contagem de produtos foram mantidos; os cartões continuam abrindo o filtro da marca correspondente.

Os arquivos SVG são contêineres com a imagem original incorporada e um enquadramento ajustado para reduzir margens. As cores e os pixels das imagens de origem foram preservados. O logo Olenka é exibido em branco por CSS sobre o cartão azul.

O HTML avulso pode ser regenerado com `python scripts/export-html.py <arquivo-de-saida.html>`. O exportador incorpora os estilos, o comportamento e as imagens, incluindo os oito logos.

Validação desta alteração: sintaxe JavaScript conferida, oito referências de logos resolvidas, SVGs com imagens incorporadas e sem referências externas, HTML avulso regenerado sem dependência da pasta assets. Não houve revisão visual automatizada do arquivo local, pois a política de navegação do navegador bloqueia URLs file://.
