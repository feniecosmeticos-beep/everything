# Logos das marcas no catálogo

Incluídos em 14/10/2026 nos cartões de marcas do início e da página Marcas. Os logos estão centralizados e os nomes repetidos abaixo deles foram removidos. A contagem de produtos foi mantida; os cartões continuam abrindo o filtro da marca correspondente. A identificação da marca permanece no logo e nos rótulos acessíveis.

Os cartões usam os arquivos PNG/WebP originais diretamente, com enquadramento por CSS para reduzir margens. As cores e os pixels das imagens de origem foram preservados. Os contêineres SVG anteriores permanecem como referência. No desktop, Olenka aparece em branco sobre azul; no celular, todos os logos aparecem sobre fundo branco para manter a legibilidade.

O HTML avulso pode ser regenerado com `python scripts/export-html.py <arquivo-de-saida.html>`. O exportador incorpora os estilos, o comportamento e as imagens, incluindo os oito logos.

Validação em 14/10/2026: oito logos carregados, centralizados e legíveis na prévia HTTP local em 390 px e no desktop de 1280 px. O HTML avulso incorpora os mesmos arquivos de imagem e estilos. A versão inicial com SVG não teve revisão visual automatizada por bloqueio da navegação file://; a revisão atual foi feita na prévia HTTP do projeto.
